# TDC Voice support and privacy

Public support documentation for TDC Voice, published with GitHub Pages.

- [Support](https://think-define-create.github.io/tdc-voice-support/support.html)
- [Privacy](https://think-define-create.github.io/tdc-voice-support/privacy.html)
- [Think Define Create](https://thinkdefinecreate.com)

Contact: info@thinkdefinecreate.com.

Pages is configured to publish the main branch root. The HTML is static, with no scripts, external fonts or analytics SDK. GitHub logs visitor IP addresses for security purposes as described on the privacy page.

To update, edit the reviewed HTML files and push to main. Keep index.html consistent with support.html. App source code, builds, recordings and private App Review contact information are maintained separately.
